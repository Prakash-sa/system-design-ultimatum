# Security Policy

This repository contains educational content and a static-site generator. It does not run a production service or collect user data.

## Report A Security Issue

If you find a security issue in the site generation code, GitHub Actions configuration, or published site, please report it privately to the maintainer before opening a public issue.

Include:

- A short description of the issue.
- Steps to reproduce it.
- The affected file, page, or workflow.
- Any suggested fix, if known.

## Out Of Scope

- General system design disagreements.
- Broken external links.
- Content corrections without a security impact.
- Vulnerabilities in third-party services described by diagrams or notes.

For non-security issues, use the normal GitHub issue templates.
